# Proposal

## Why

论坛仍在运营，但 Laravel 6 / PHP 7.4 需要单独维护过时的运行环境。帖子不到 1000 条、评论不到 2000 条，Elasticsearch 的运维和升级成本已超过普通搜索的收益；高级检索已有独立 Dify / mudrenRAG 服务承担。

## What Changes

- 将普通帖子搜索改为 MySQL 参数化 `INSTR` 子串查询，支持中文子串、标题优先、稳定分页和安全高亮，保持现有 `/threads/search` 响应结构和公开可见性规则。
- 移除 Elasticsearch、Scout、索引同步任务和相关配置、部署步骤。
- 按维护者确认移除未使用的七牛依赖及第三方登录入口/依赖，保留邮件与账号密码登录；历史账号关联数据不删除。
- **BREAKING**：最低运行环境提高到 PHP 8.3，框架升级 Laravel 13；升级或替换不兼容的认证、存储、邮件、上传等依赖。
- 保留现有前端使用的密码登录、令牌撤销、注册、帖子、评论、关系和通知接口，以及 RAG 使用的帖子 ID、`App\Thread` 多态类型和正文响应。
- 保持 MySQL 5.7.40 兼容；升级数据库不是本次前提。补充回归测试、兼容性核验和简洁的停机升级/回退说明。

## Capabilities

### New Capabilities

- `database-thread-search`: 无搜索服务依赖的普通帖子搜索及现有前端响应兼容。
- `modern-forum-runtime`: Laravel 13 / PHP 8.3+ 运行环境、历史数据兼容、现有业务与集成接口的升级保障。

### Modified Capabilities

无。仓库目前没有主规范；本次为已有系统建立升级所需的能力规范。

## Impact

- 后端：`composer.json` / lock、启动配置、服务提供者、中间件、模型、搜索控制器、Passport、邮件/上传/文件系统适配、测试及运维文档。
- 外部消费者：只读核对 `bbs.mud.ren` 前端和 `mudrenRAG` 的接口要求；保持契约，不重写前端或知识库。
- 数据：保留论坛业务表、主键、多态类型及 Passport 密钥；如依赖升级需要表结构补齐，采用可在现有库执行的增量迁移并记录回退要求。
- 运维：允许短时维护窗口，备份后升级并验收；不引入双写、双集群、在线索引迁移、全文分词或新的搜索服务。
