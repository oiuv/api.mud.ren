# Design

## Context

动机见 proposal.md。当前框架锁定 Laravel 6.20.45 / Passport 7.5.1，测试基线为 PHP 7.4 下 37 个测试、331 个断言通过。测试使用内存 SQLite，并隔离本地环境、配置缓存、邮件与队列。现网是 MySQL 5.7.40，内容总量不足 3000 条。

搜索位于 ThreadController，Scout 通过自定义 EsEngine 映射命中结果；Thread 的保存事务外还会派发索引同步。前端搜索页和导航搜索依赖 `data/links/meta` 及 `highlights.title/content`。前端认证直接调用 `/oauth/token` 密码授权。RAG 读取既有数据库并调用 `/threads/{id}`，依赖 `App\Thread` 多态类型和 `content.markdown`。

## Goals / Non-Goals

**Goals:**
- 在同一后端逐步替换依赖，保留业务代码、数据库和消费者契约。
- 用独立可验证的搜索阶段降低后续框架升级排错范围。
- 本地完成代码、依赖解析、测试与可执行升级说明，明确哪些真实服务尚未验证。

**Non-Goals:**
- 不新增全文索引、中文分词、搜索专表、向量服务或 AI 调用。
- 不重建论坛、不重命名模型命名空间、不重写前端；不做大流量在线迁移设计。
- 不自动操作现网数据库、不部署、不替换现网密钥。

## Decisions

### 1. 搜索采用关系查询与字面子串

查询已发布主题的标题及关联正文，使用绑定参数的 `INSTR(LOWER(字段), LOWER(?)) > 0`。MySQL 5.7.40 的 utf8mb4_unicode_ci 实测暴露了 LIKE 双重转义字符的匹配差异，因此采用不解释通配符的子串函数，`%`、`_`、`!`、反斜杠均按字面匹配。中文无需分词；空查询返回空分页，数组等非法参数返回验证错误，查询最长 100 个字符。优先标题命中，其次发布时间倒序、ID 倒序；每页 10 条。输入按首尾去空白后的完整子串匹配，不实现 ES 模糊纠错或多词语义查询。

不选择 MySQL FULLTEXT/ngram：当前数据规模和目标无需分词配置或额外索引。查询使用 `published()` 范围，关联正文遵守软删除；评论不进入主题搜索。

高亮从纯文本片段生成，先 HTML 转义，再插入系统控制的 `<em>`；保持前端使用的高亮字段。正文优先 markdown，HTML 正文转纯文本。模型保留独立公开性判断，去除 Scout trait、索引序列化、ES Engine/映射和索引配置。

### 2. 保留现有 Laravel 应用结构并升级到 13

不生成新应用覆盖旧项目。保留 `app/` 模型与旧式 Kernel/Provider 布局，按官方跨版本升级要求更新移除的 API、日期转换、异常签名、代理/CORS 中间件、邮件/文件系统配置和测试工厂。目标约束 PHP `^8.3` / Laravel `^13.0`，使用 Herd 的 PHP 8.x 执行 Composer 和测试，依赖真实解析并提交 lock。

依赖处理原则：使用支持目标框架的稳定版本；若旧适配包已停更，优先采用框架原生能力或维护中的底层 SDK 加小型适配，保留其对外行为。涉及 Passport、阿里云邮件、上传、表情、关系和活动日志，不能为解决依赖冲突而静默删除业务功能。用户已确认七牛和第三方登录未使用，移除依赖与第三方登录路由，保留历史 profiles 数据；上传沿用当前 public 磁盘。邮件使用 Symfony Mailer 与项目内 DirectMail 适配器。为保留历史行为，follow 使用 1.x、Parsedown 使用兼容稳定 Extra 的 1.7.x；Composer platform 固定 PHP 8.3.0，避免在 PHP 8.4 解析出要求更高的依赖。精确版本及替换结果记录在实施验证记录中。

### 3. 认证与历史数据库采取兼容升级

保留 Passport OAuth 接口及密码授权，显式启用密码授权。保留数据库中的客户端标识、用户 ID 和现有密钥；按目标 Passport 实际结构处理增量字段和旧客户端兼容。测试覆盖密码登录、受保护接口与令牌撤销，必要时明确一次重新登录要求，而非承诺无法验证的旧令牌持续有效。

业务迁移保留历史迁移记录，不使用 `migrate:fresh` 升级现网。MySQL 5.7 兼容仍为约束；SQLite 测试通过不能代表 MySQL 实机验收。所有验证连接必须指向明确的测试库。

### 4. 验证与发布按小项目规模执行

保留现有权限、内容净化、草稿隔离、原子计数、事务后提及任务以及 RAG 连续读取回归。补充搜索的中文、通配符字面量、排序分页、可见性和高亮安全测试。框架升级后执行完整回归、路由/配置启动检查和 Composer 平台检查；在可用的 Herd PHP 版本上复测。

## Risks / Trade-offs

- [搜索相关度降低] → 普通搜索明确为字面子串；复杂检索继续使用已有 AI。
- [旧依赖无兼容版本] → 逐项解析与替换，测试对外行为并记录部署配置变动。
- [Passport 跨版本变化] → 单独测试客户端、签发及撤销，保留密钥和数据备份，不运行破坏性重装命令。
- [SQL 方言差异] → 使用 MySQL 5.7 支持的查询；记录实际 MySQL 验证状态，发布前完成测试库验收。
- [外部服务凭据/测试环境不可用] → 适配器自动化测试隔离网络；文档列出邮件的真实服务验收步骤，不把模拟测试写成真实验证。

## Migration Plan

1. 备份现网数据库、`.env`、Passport 密钥和上传文件，保留旧版本及 lock。
2. 在测试环境安装目标 PHP 和新 lock 依赖，导入备份到独立测试库，执行增量迁移，验证登录、发帖、评论、搜索、上传、邮件、RAG。
3. 短时维护窗口内备份最终数据，停止旧队列工作进程，切换代码和 PHP，执行已验收的迁移并重建配置缓存。
4. 启动工作进程，完成基本验收再恢复访问。确认后停止 Elasticsearch。
5. 失败时停止新版本写入，恢复旧代码/PHP、数据库备份、配置和密钥，启动旧服务。涉及数据库变更时以备份恢复为回退依据，避免未经验证的跨大版本迁移回滚。
